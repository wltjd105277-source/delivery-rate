# 쿠팡 납품률 · 미출고 관리 사이트

라인업시스템(주) 사내용 — `쿠팡 납품률 및 미출고 사유 관리.xlsx`를 그대로 올리면 자동으로 월별로 분류 · 집계해 주는 단일 페이지 웹앱.

## 폴더 구성

```
coupang_app/
├── index.html      ← 메인 페이지
├── app.js          ← 모든 로직 (파싱·집계·차트·UI)
├── server.py       ← (선택) 로컬 실행용 초간단 서버
├── render.yaml     ← Render 정적 사이트 배포 설정
└── README.md
```

브라우저 안에서 모든 처리(엑셀 파싱·집계·차트)를 끝내고, 데이터는 브라우저 `localStorage`에 저장됩니다. **별도 DB·서버 없이 동작**합니다.

## 1. 가장 빠른 사용법 (서버 없이)

`index.html`을 더블클릭하면 끝입니다. 회사 공유폴더/USB에 넣어 두고 바로 쓸 수 있어요.

## 2. 로컬에서 서버로 띄우기 (선택)

```bash
cd coupang_app
python server.py
# → http://localhost:8080
```

## 3. Render에 배포 (사내 URL로 쓰고 싶을 때)

기존 `smarts.onrender.com`처럼 Render Static Site로 5분 안에 올릴 수 있습니다.

1. 이 폴더(`coupang_app/`)를 GitHub 새 리포에 push
2. https://dashboard.render.com → **New +** → **Static Site** → 리포 선택
3. 설정값:
   - **Branch**: `main`
   - **Build Command**: 비워두기
   - **Publish Directory**: `.` (또는 `coupang_app`)
4. **Create Static Site** → 1~2분 후 `xxx.onrender.com` URL 발급

이 폴더에 `render.yaml`이 들어 있으므로 Render에서 위 설정이 자동으로 채워집니다.

## 사용 흐름

1. 첫 화면 또는 「데이터 관리」 탭에서 엑셀 업로드 (드래그 드롭 / 파일 선택 / 여러 파일 한 번에)
2. 헤더(발주일자, 발주번호, 상품명, 모델명, 발주수량, 실제출고량, 미출고수량, 미출고 금액, 미출고사유, 비고)를 자동 인식
3. **발주일자**를 보고 자동 월별 분류 → 상단 「기간」에서 월/전체 선택
4. 탭 별 보기:
   - **대시보드** — 선택 월 KPI(전월 대비), 월별 추이, 사유 분포, 일별 추이, 손실 TOP 10
   - **사유별 분석** — 사유×월 매트릭스(히트맵), 사유 비중 추이(100% 적층), 사유별 TOP 상품
   - **상품(모델)별** — 모델별 미출고 TOP 50과 주요 사유
   - **상세 검색** — 검색어/사유/기간/정렬 + CSV·XLSX 내보내기
   - **데이터 관리** — 업로드 이력·전체 초기화

## 자주 묻는 것

**Q. 매월 새 엑셀이 나오는데 어떻게 관리하나요?**
A. 매월 새 파일을 업로드하면 됩니다. `발주번호+상품명+수량+발주일자` 키로 중복은 자동 제거되므로, 같은 파일을 여러 번 올려도 데이터가 중복되지 않습니다.

**Q. 데이터가 어디에 저장되나요?**
A. 사용한 브라우저의 `localStorage`. 다른 PC에서 보려면 그 PC에서도 엑셀을 한 번 업로드하면 됩니다.
완전히 초기화하려면 「데이터 관리 → 전체 초기화」.

**Q. 엑셀 컬럼명이 다르면?**
A. `app.js` 상단 `HEADER_SYNONYMS` 사전에 매핑이 들어있습니다. 실제 시트의 컬럼명을 추가하면 자동 인식됩니다.

**Q. 모바일에서도 보이나요?**
A. 반응형으로 동작합니다 (1100px·640px 브레이크포인트).
